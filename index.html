Antes de começar,
vale saber.

Essência usa os quatro temperamentos como uma linguagem simbólica para refletir sobre atitudes, relações e emoções.

Este questionário autoral não é um instrumento psicológico validado e não oferece diagnóstico. Os personagens de Divertida Mente são usados aqui como metáforas criativas. A associação com temperamentos é uma proposta deste teste, não uma classificação do filme. Esta é uma experiência independente, sem vínculo com Disney ou Pixar.

Como calculamos: cada uma das 15 escolhas vale um ponto para um temperamento. As porcentagens são arredondadas e somam 100%. Em caso de empate, apresentamos um perfil combinado, sem inventar um vencedor.

Sua privacidade: o teste funciona no próprio navegador. O resultado é salvo neste dispositivo, quando o armazenamento está disponível. Suas respostas e os vídeos ficam neste navegador. Nada é enviado a um servidor durante o teste. Os links de fonte só são abertos se você clicar neles. Compartilhar é uma escolha sua.
